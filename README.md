# NextKey

**Intelligently ranks Mythic+ keys for your group.**

NextKey is a World of Warcraft addon designed to help you and your group make smarter decisions about which Mythic+ keys to run. It analyzes your group's composition and Raider.IO scores to provide intelligent recommendations, maximizing your chances of success.

## Key Features

- **Intelligent Key Suggestions**: Recommends the best Mythic+ keys for your group based on player scores and dungeon data.
- **Raider.IO Integration**: Automatically pulls Raider.IO data to ensure accurate scoring and recommendations.
- **Group Score Calculation**: Calculates a comprehensive group score to estimate your potential for success in different dungeons.
- **PUG Helper**: Assists with the process of finding and joining Pick-Up Groups (PUGs).
- **Dungeon and Loot Information**: Provides easy access to dungeon-specific information, including loot tables.
- **User-Friendly UI**: A clean and intuitive user interface to display key recommendations and group information.
- **Comprehensive Debug and Testing Tools**: Includes a full suite of tools for developers and advanced users to test and debug the addon.

## Installation

1.  **Download the latest release** from the [releases page](https://github.com/your-username/your-repo/releases).
2.  **Extract the archive** to find the `NextKey` folder.
3.  **Copy the `NextKey` folder** into your `World of Warcraft\\_retail_\\Interface\\AddOns` directory.
4.  **Restart World of Warcraft**.

## Usage

You can access most of the addon's features through the main UI, but here are some useful slash commands:

-   `/nk config`: Opens the options panel.
-   `/nk debug`: Toggles the debug mode.
